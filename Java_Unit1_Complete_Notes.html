Object-Oriented Programming Paradigms

▼
🇮🇳 Hinglish Explanation
Bhai, OOP ek programming style hai jisme hum duniya ko real-life objects ki tarah sochte hain. Jaise — ek Car ek object hai jiske paas properties hain (color, speed) aur behaviors hain (drive, brake). Programming mein hum inhe class aur methods kehte hain. Yeh approach code ko organized, reusable, aur samajhne mein aasan banata hai!
📖 English Definition
Object-Oriented Programming (OOP) is a programming paradigm based on the concept of "objects", which are instances of classes. It organizes software design around data and objects rather than functions and logic. OOP models real-world entities as software objects that have attributes (data) and behaviors (methods).
Programming Paradigms — Types
🔧 Procedural

Code executes step-by-step. Example: C Language. Functions do the work.

🎯 Object-Oriented

Code organized around objects. Example: Java, C++, Python. Classes define objects.

📐 Functional

Functions are first-class citizens. Example: Haskell, Lisp. Pure functions, no side effects.

📦 Declarative

Describe WHAT to do, not HOW. Example: SQL, HTML. Less focus on control flow.

📊 OOP vs Procedural Paradigm
PROCEDURAL APPROACH            OBJECT-ORIENTED APPROACH
─────────────────────          ──────────────────────────────
  main()                         ┌─────────────────────┐
    │                            │   Class: Car         │
    ├─ getData()                  │ ─────────────────── │
    ├─ processData()              │  Attributes:         │
    ├─ displayData()              │    color, speed      │
    │                            │  Methods:            │
  Functions are                  │    drive(), brake()  │
  PRIMARY units                  └─────────────────────┘
                                   Objects are PRIMARY units
✅ Advantages
  • Code Reusability (via inheritance)
  • Easy to maintain & debug
  • Models real-world problems naturally
  • Modularity & encapsulation
  • Security via data hiding
❌ Disadvantages
  • More complex than procedural
  • Larger program size
  • Slower execution (sometimes)
  • Not suitable for small problems

Features of Object-Oriented Programming

▼
🇮🇳 Hinglish Explanation
OOP ke 4 main pillars hain — Encapsulation, Abstraction, Inheritance, Polymorphism. Yaad karo ek school ka example: Teacher class → Subject Teacher class (Inheritance). Teacher ki personal details hidden (Encapsulation). Teacher ka kaam batata hai "padhana" lekin andar ka mechanism hide (Abstraction). Ek teacher multiple subjects padha sakta hai differently (Polymorphism). Easy hai na! 🎯
🧠 Mnemonic
"A PIE" — Abstraction, Polymorphism, Inheritance, Encapsulation
Ya yaad karo: "Ek Acha Padha-likha Insaan" = E(ncapsulation) A(bstraction) P(olymorphism) I(nheritance)
1️⃣ Encapsulation
Definition
Bundling data (variables) and methods that operate on that data within a single unit (class), and restricting direct access to some components. Achieved via access modifiers (private, public). 
  ┌────────────────────────────────────────┐
  │           Class: BankAccount           │
  │ ────────────────────────────────────── │
  │  Private (Hidden):                     │
  │    - balance = 50000                   │
  │    - pin = 1234                        │
  │ ────────────────────────────────────── │
  │  Public (Accessible):                  │
  │    + deposit(amount)                   │
  │    + withdraw(amount)                  │
  │    + getBalance()                      │
  └────────────────────────────────────────┘
  Data is PROTECTED. Only methods can access it!
JAVA — Encapsulation
class BankAccount {
    private double balance;  // hidden data

    public void deposit(double amount) {
        if (amount > 0) balance += amount;
    }

    public double getBalance() {
        return balance;  // controlled access
    }
}
2️⃣ Abstraction
Definition
Hiding the implementation details and showing only the essential features to the user. Like a car's steering wheel — you don't need to know how it's mechanically connected, you just turn it!
JAVA — Abstraction
abstract class Animal {
    abstract void sound();  // abstract - no body

    void breathe() {
        System.out.println("Breathing...");
    }
}

class Dog extends Animal {
    void sound() {
        System.out.println("Woof!");  // implementation
    }
}
3️⃣ Inheritance
Definition
A mechanism where one class acquires the properties and behaviors of another class. The class that is inherited from is called Parent/Super class and the one that inherits is called Child/Sub class. 
         ┌──────────────────┐
         │   Animal (Parent) │
         │  + name           │
         │  + eat()          │
         └────────┬─────────┘
                  │ extends
        ┌─────────┴──────────┐
        │                    │
  ┌─────▼──────┐    ┌────────▼──────┐
  │ Dog (Child) │    │  Cat (Child)  │
  │ + bark()    │    │  + meow()     │
  └────────────┘    └───────────────┘
  Dog & Cat INHERIT: name, eat() from Animal
JAVA — Inheritance
class Animal {
    String name;
    void eat() { System.out.println(name + " is eating"); }
}

class Dog extends Animal {
    void bark() { System.out.println("Woof Woof!"); }
}

public class Main {
    public static void main(String[] args) {
        Dog d = new Dog();
        d.name = "Tommy";
        d.eat();  // Inherited from Animal
        d.bark(); // Dog's own method
    }
}
4️⃣ Polymorphism
Definition
Greek: "Many Forms". Ability of an object to take many forms. One method name can behave differently based on the object or parameters. Two types: Compile-time (Overloading) and Runtime (Overriding).
JAVA — Polymorphism
// Compile-time (Overloading)
class Calculator {
    int add(int a, int b) { return a + b; }
    double add(double a, double b) { return a + b; }
    int add(int a, int b, int c) { return a+b+c; }
}

// Runtime (Overriding)
class Shape {
    void draw() { System.out.println("Drawing Shape"); }
}
class Circle extends Shape {
    void draw() { System.out.println("Drawing Circle"); }
}
🎯
Exam Alert Pillars ka full form yaad karo: Encapsulation (data bundling + hiding), Abstraction (hide complexity), Inheritance (IS-A relationship), Polymorphism (many forms). Difference between Abstraction vs Encapsulation: Abstraction hides complexity, Encapsulation hides data.

Bytecode Interpretation

▼
🇮🇳 Hinglish Explanation
Jab hum Java code likhte hain aur compile karte hain, toh directly machine code nahi banta. Pehle ek intermediate format banta hai — jise Bytecode kehte hain. Yeh bytecode JVM padhta hai aur machine-specific instructions mein convert karta hai. Isliye ek .class file Windows, Linux, Android — sab jagah chalti hai! 🌍 
  ┌────────────────┐     javac      ┌─────────────────┐     JVM      ┌────────────┐
  │  HelloWorld.java│  ──────────►  │ HelloWorld.class  │ ──────────►  │  Output    │
  │  (Source Code)  │  (Compiler)   │   (Bytecode)      │ (Interprets) │            │
  └────────────────┘               └─────────────────┘               └────────────┘
       Human                       Platform-Independent               Platform-Specific
       Readable                     Intermediate Code                 Native Execution
Definition
Bytecode is an intermediate representation of a Java program, generated by the Java compiler (javac). It is not machine code but a set of instructions for the JVM. The JVM then interprets or compiles this bytecode into native machine instructions at runtime.
Two Execution Methods in JVM
🐢 Interpreter

Reads bytecode line by line and executes. Slower but starts immediately. Used for infrequent code.

⚡ JIT Compiler (Just-In-Time)

Compiles "hot" (frequently used) bytecode to native code at runtime. Much faster execution after first run.

💡 WORA: "Write Once, Run Anywhere" — Bytecode ka platform independent hona hi Java ko WORA deta hai. Ek .class file Android tablet se leke Windows PC tak chalti hai!

Variables and Arrays

▼
🇮🇳 Hinglish Explanation
Variable = ek named memory location jisme data store hota hai. Jaise ghar ka address hai — address se ghar dhundh lete ho, variable se data dhundh lete ho. Aur Array = ek row ke boxes ka group jisme same type ka data store hota hai. Jaise rail ke dabhe — sab connected hain numbered hain!
Types of Variables
🏠 Local Variable

Method ke andar declare. Only accessible within that method. No default value.

🏛️ Instance Variable

Class ke andar, method ke bahar. Each object has its own copy. Has default value.

⚡ Static Variable

Class level. Shared among all objects. Declared with static. One copy exists.

JAVA — Variable Types
class VariableDemo {
    int instanceVar = 10;        // Instance variable
    static int staticVar = 0;   // Static variable

    void show() {
        int localVar = 5;          // Local variable
        System.out.println(localVar + instanceVar + staticVar);
    }
}
Arrays in Java
Definition
An array is a collection of similar type elements stored in contiguous memory locations. Arrays in Java are objects. They have a fixed size once created.
1D Array:
  int[] marks = {85, 90, 78, 92, 88};

   Index:  [0]  [1]  [2]  [3]  [4]
          ┌────┬────┬────┬────┬────┐
  Value:  │ 85 │ 90 │ 78 │ 92 │ 88│
          └────┴────┴────┴────┴────┘
  marks[0] = 85, marks[2] = 78 ...
2D Array:
  int[][] matrix = {{1,2,3},{4,5,6},{7,8,9}};

          [0]  [1]  [2]
     [0]   1    2    3
     [1]   4    5    6

JAVA — Arrays Complete
public class ArrayDemo {
    public static void main(String[] args) {

        // 1D Array — Declaration & Initialization
        int[] marks = new int[5];    // size 5
        marks[0] = 85;
        marks[1] = 90;

        // Shorthand
        int[] scores = {10, 20, 30, 40, 50};

        // Loop through array
        for (int i = 0; i < scores.length; i++) {
            System.out.print(scores[i] + " ");
        }

        // Enhanced for loop
        for (int s : scores) {
            System.out.print(s + " ");
        }

        // 2D Array
        int[][] matrix = {{1,2,3},{4,5,6}};
        System.out.println(matrix[1][2]);  // Output: 6
    }
}

JAVA — Operators Demo
public class OperatorDemo {
    public static void main(String[] args) {
        int a = 10, b = 3;

        // Arithmetic
        System.out.println(a + b);  // 13
        System.out.println(a % b);  // 1 (modulus)

        // Pre and Post Increment
        int x = 5;
        System.out.println(x++);   // 5 (post: use then increment)
        System.out.println(++x);   // 7 (pre: increment then use)

        // Ternary
        int max = (a > b) ? a : b;
        System.out.println("Max: " + max);  // 10

        // Bitwise AND
        System.out.println(5 & 3);  // 101 & 011 = 001 = 1

        // Logical Short-Circuit
        boolean r = (5 > 3) && (2 < 4);  // true
    }
}
💡 Short-Circuit Evaluation: && mein agar pehla false hai toh second evaluate nahi hota. || mein agar pehla true hai toh second nahi chekta!

Control Statements

▼
🇮🇳 Hinglish Explanation
Control Statements program ke execution flow ko control karte hain. By default code top-to-bottom chalta hai. Control statements se hum decide karte hain — kaunsa code run hoga, kab run hoga, aur kitni baar run hoga. 3 types: Selection (if/switch), Iteration (loops), Jump (break/continue/return)!
1. Selection Statements
JAVA — if-else & switch
// if-else if-else
int marks = 75;

if (marks >= 90) {
    System.out.println("Grade: A+");
} else if (marks >= 75) {
    System.out.println("Grade: A");
} else if (marks >= 60) {
    System.out.println("Grade: B");
} else {
    System.out.println("Grade: C");
}

// switch
int day = 3;
switch (day) {
    case 1: System.out.println("Monday"); break;
    case 2: System.out.println("Tuesday"); break;
    case 3: System.out.println("Wednesday"); break;
    default: System.out.println("Other day");
}
2. Iteration (Loops)
JAVA — All Loops
// for loop
for (int i = 1; i <= 5; i++) {
    System.out.print(i + " "); // 1 2 3 4 5
}

// while loop
int i = 1;
while (i <= 5) {
    System.out.print(i + " ");
    i++;
}

// do-while loop (runs at least once!)
int j = 10;
do {
    System.out.println(j);  // prints 10, then checks condition
    j++;
} while (j < 5);  // false but printed once!

// Enhanced for loop (for arrays/collections)
int[] arr = {1,2,3,4,5};
for (int x : arr) {
    System.out.print(x + " ");
}
LoopCondition CheckMin ExecutionsBest Use
forBefore0 (if false initially)Known number of iterations
whileBefore0 (if false initially)Unknown iterations
do-whileAfter1 (at least once!)Menu-driven programs
3. Jump Statements
JAVA — break, continue, return
// break — exits the loop immediately
for (int i = 1; i <= 10; i++) {
    if (i == 5) break;
    System.out.print(i + " ");  // 1 2 3 4
}

// continue — skips current iteration
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;
    System.out.print(i + " ");  // 1 3 5 7 9
}

// return — exits from the method
static int max(int a, int b) {
    if (a > b) return a;
    return b;
}

class PassByValueDemo {
    static void change(int x) {
        x = 100;  // changes local copy, not original
    }

    static void changeArray(int[] arr) {
        arr[0] = 999;  // reference copy — changes original array!
    }

        change(a);
        System.out.println(a);  // 10 — not changed!

}

Abstract Classes

▼
🇮🕵️Hinglish Explanation
Abstract Class ek aisi class hai jo directly instantiated nahi ho sakti (object nahi ban sakta directly). Yeh ek incomplete blueprint hai. Isme abstract methods hote hain (body nahi hoti) — child class ko implement karna padta hai. Jaise "Shape" abstract hai, "Circle" aur "Rectangle" concrete implementations hain!
Definition
An abstract class is a class declared with the abstract keyword. It may contain abstract methods (no body) and concrete methods (with body). Cannot be instantiated directly. Must be subclassed, and all abstract methods must be implemented. 
  abstract class Shape {        ← Can't do: new Shape()
      abstract double area();   ← No body, must be overridden
      void display() { ... }    ← Concrete method (has body)
  }

   ┌─────┴──────┐
   │            │
   ▼            ▼
Circle       Rectangle
area()=πr²   area()=l*w
(implemented) (implemented)
JAVA — Abstract Class
abstract class Shape {
    String color;

    Shape(String color) {
        this.color = color;
    }

    // Abstract method — no body
    abstract double area();
    abstract double perimeter();

    // Concrete method — has body
    void display() {
        System.out.println("Color: " + color + " | Area: " + area());
    }
}

class Circle extends Shape {
    double radius;

    Circle(String color, double r) {
        super(color);
        radius = r;
    }

    @Override
    double area() { return Math.PI * radius * radius; }

    @Override
    double perimeter() { return 2 * Math.PI * radius; }
}

class Main {
    public static void main(String[] args) {
        // Shape s = new Shape("Red"); // ERROR! Can't instantiate
        Shape s = new Circle("Red", 5.0);  // OK! Upcasting
        s.display();
    }
}

Abstract Class vs Interface Comparison Abstract class: partial abstraction (0-100%), can have constructors, can have instance variables, can have method body. Interface: 100% abstraction (Java 7), can have default/static methods (Java 8+), all methods public abstract by default, all variables public static final.

▼
🇮🕵️Hinglish Explanation
final keyword ka matlab hai — "band karo!". Variable ko final karo → constant ban jata hai (change nahi hoga). Method ko final karo → override nahi hogi. Class ko final karo → inherit nahi hogi. Java mein Math.PI final variable hai!

Interface in Java

▼
🇮🕵️Hinglish Explanation
Interface ek pure abstract blueprint hai (Java 7 tak) jisme sirf method signatures hoti hain — koi implementation nahi. Class implements keyword se interface use karta hai. Interface se Java mein multiple inheritance achieve hoti hai! Java 8 mein default aur static methods allow hue, Java 9 mein private methods bhi!
Definition
An interface is a reference type in Java, similar to a class, that can contain only abstract methods (Java 7), constants, default methods (Java 8+), and static methods. Classes implement interfaces using the implements keyword. 
  Interface: Flyable              Interface: Swimmable
  ──────────────────              ────────────────────
  + fly()  (abstract)             + swim() (abstract)
          │                               │
          └──────────┬────────────────────┘
                     │ implements
                     ▼
            class Duck implements Flyable, Swimmable {
                fly()  → override
                swim() → override
            }
  Multiple Interface Implementation = Multiple Inheritance in Java!
JAVA — Interface Complete Example
// Interface definition
interface Drawable {
    int SIZE = 100;  // implicitly public static final
    void draw();     // implicitly public abstract

    // Java 8: default method
    default void printInfo() {
        System.out.println("Drawing with size: " + SIZE);
    }
}

interface Resizable {
    void resize(int factor);
}

// Class implementing multiple interfaces
class Circle implements Drawable, Resizable {
    int radius;

    Circle(int r) { radius = r; }

    @Override
    public void draw() {
        System.out.println("Drawing Circle with radius: " + radius);
    }

    @Override
    public void resize(int factor) {
        radius *= factor;
        System.out.println("New radius: " + radius);
    }
}

// Interface can extend another interface
interface Shape extends Drawable, Resizable {
    double area();
}

Member Access in Inheritance

🇮🕵️Hinglish Explanation
Inheritance mein member access control bahut important hai. Child class ko parent ke public aur protected members accessible hote hain. Private members child mein accessible nahi hote (but exist karte hain — inherited hain, directly access nahi). Aur super se parent members access kar sakte hain!
JAVA — Member Access in Inheritance
class Parent {
    private int pvt = 1;       // private
    int def = 2;               // default (package)
    protected int prot = 3;   // protected
    public int pub = 4;        // public

    private void privateMethod() { System.out.println("Private"); }
    public void publicMethod()  { System.out.println("Public"); }
}

class Child extends Parent {
    void test() {
        // System.out.println(pvt);        // ERROR! Cannot access private
        System.out.println(def);         // OK (same package)
        System.out.println(prot);        // OK (protected)
        System.out.println(pub);         // OK (public)

        // privateMethod();  // ERROR!
        publicMethod();                  // OK
    }
}

String Handling in Java

▼
🇮🕵️Hinglish Explanation
Java mein String ek class hai — primitive nahi! String immutable hoti hai — matlab ek baar create hone ke baad change nahi hoti. "Hello" likhte hi String Pool mein object ban jata hai. StringBuilder mutable hai aur faster hai (thread unsafe). StringBuffer mutable + thread-safe hai lekin thoda slow!
Definition
String is a sequence of characters represented by the java.lang.String class. Strings in Java are immutable — once created, their value cannot be changed. Any modification creates a new String object.
String Creation — Two Ways
  1. String Literal (uses String Pool):
     String s1 = "Hello";
     String s2 = "Hello";  ← Both point to SAME object in Pool!

     String Pool:
     ┌─────────────────────────┐
     │  "Hello" (only ONE obj)  │
     │  s1 ──────────────────► │
     │  s2 ──────────────────► │
     └─────────────────────────┘

  2. new keyword (uses Heap):
     String s3 = new String("Hello");  ← New object in Heap ALWAYS
     String s4 = new String("Hello");  ← Another new object!

     Heap: s3 → {Hello}   s4 → {Hello}  (2 separate objects)

  s1 == s2     → true  (same pool reference)
  s1 == s3     → false (s3 is in heap)
  s1.equals(s3)→ true  (same content)
